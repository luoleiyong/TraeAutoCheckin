# 云端签到（Cloudflare Worker）

装在电脑上的版本要开机才会签到。这个版本把签到搬到 Cloudflare，**电脑关机也会每天自动签**。

整套东西只有一个 `worker.js` 文件，跑在 Cloudflare 的免费额度里：

| 项目 | 免费额度 | 实际占用 |
| --- | --- | --- |
| Worker 请求 | 10 万次 / 天 | 每天 1 次（含手动操作也就几十次） |
| KV 读写 | 10 万读 / 1 千写 / 天 | 每个账号每天写 1～2 次 |
| Cron 触发器 | 免费套餐可用 | 1 个 |

一个账号、每天签到一次，常年用不到额度的 1%。

---

## 一、准备

只需要三样东西：

1. 一个 Cloudflare 账号（免费注册，不用绑卡）
2. 手机或电脑上的浏览器
3. 你的 Trae 账号（扫码登录用）

---

## 二、部署（网页版，5 分钟）

### 1. 建一个 Worker

打开 <https://dash.cloudflare.com> → 左侧 **Workers & Pages** → **创建** → **Worker** → 起个名字（例如 `trae-checkin`）→ **部署**。

进去后点 **编辑代码**，把默认的示例代码全删掉，粘贴本目录 `worker.js` 的全部内容 → **部署**。

### 2. 建一个 KV 命名空间

左侧 **Workers & Pages** → **KV** → **创建命名空间**，名字随便（例如 `trae-kv`）。

回到你的 Worker → **设置** → **绑定** → **添加绑定** → 选 **KV 命名空间**：

- 变量名称必须填 `KV`（大小写一致，代码里写死了）
- KV 命名空间选刚建的那个

### 3. 加三个机密变量

Worker → **设置** → **变量和机密** → **添加**，类型选 **机密**（Secret）：

| 名称 | 值 | 说明 |
| --- | --- | --- |
| `ADMIN_TOKEN` | 自己定，建议 20 位以上 | 打开控制台时要输的口令 |
| `MASTER_KEY` | 见下方生成方法 | 加密账号令牌用的主密钥 |
| `CRON_SECRET` | 自己定，随机串 | 外部手动触发 /cron 时用，可选 |

`MASTER_KEY` 必须是 **32 字节随机数的 base64**（44 个字符，以 `=` 结尾）。用任一浏览器控制台（F12）跑一行生成：

```js
btoa(String.fromCharCode(...crypto.getRandomValues(new Uint8Array(32))))
```

> 这个密钥一旦泄露，别人拿到 KV 里的数据就能解开你的令牌。**不要写进代码、不要发群里。**
> 换了密钥，之前托管的账号会全部解不开，需要重新扫码。

### 4. 加普通变量

同一页面 **添加** → 类型选 **文本**：

| 名称 | 值 |
| --- | --- |
| `CRON_ENABLED` | `1` |

（只是让控制台显示「已开启」，没有实际功能作用。）

### 5. 加 Cron 触发器

Worker → **设置** → **触发器** → **Cron 触发器** → **添加**：

```
10 0 * * *
```

Cron 用的是 **UTC 时间**，`10 0 * * *` = 每天 UTC 00:10 = **北京时间 08:10**。

想换时间就换算一下：北京时间减 8 小时，例如 07:30 → `30 23 * * *`（前一天 UTC）。

### 6. 打开控制台

Worker 页面顶部的 `https://trae-checkin.<你的子域>.workers.dev` 就是控制台地址。

**手机浏览器也能直接打开**，加到桌面图标当作 App 用。

输入第 3 步设置的 `ADMIN_TOKEN` → 进入。

## 三、托管账号

### 流程

1. 控制台点 **扫码托管** → **生成登录链接**
2. 点 **复制链接**，在**同一台手机**的浏览器里打开（微信里打开也行，但建议用系统浏览器）
3. 登录你的 Trae 账号 → 确认授权
4. 授权完成后页面会跳到 `http://127.0.0.1:17388/authorize?authCodeInfo=...`，**打不开是正常的**
5. 把地址栏里那一整段复制下来
6. 回到控制台，粘到第二个输入框 → 点 **完成托管**

托管成功后会立刻跑一次签到，结果直接显示在账号卡片上。

### 为什么要在手机上打开、又把地址粘回来

Trae 的登录页只认 `127.0.0.1` 开头的回调地址——这是它防止授权码被第三方网站截走的设计。云端没有「本机」，所以拿不到那次跳转。

变通办法是：把这个**只能在本机打开、打开也是白屏**的地址手动搬回来。地址里带的授权码是一次性的、且有 15 分钟时效，用完即失效。

### 想加第二个账号

重复上面流程即可。每个账号都会独立生成一套设备身份（设备号 + P-256 密钥对），互不影响。

## 四、日常使用

| 操作 | 位置 |
| --- | --- |
| 看今天签没签 | 打开控制台首页 |
| 立刻签一次 | 卡片上的 **立即签到** |
| 全部重签 | 顶部 **全部签到** |
| 删掉某个账号 | 卡片上的 **删除** |

### 状态含义

| 状态 | 意思 | 要做什么 |
| --- | --- | --- |
| 已签到 | 今天签过了 | 无 |
| 待运行 | 还没跑过 | 等 08:10 或手动点 |
| 冷却中 | 服务端限流 | 等倒计时结束 |
| 需重新扫码 | 登录态失效 | 删掉重新托管 |
| 失败 | 其它错误 | 看卡片上的原因 |

## 五、它到底做了什么

```
每天 08:10  Cron 触发
      ↓
读 KV 里的账号（AES-256-GCM 加密）
      ↓
本地检查：令牌还有效吗 → 无效则用 refreshToken 换新的
      ↓
POST 查签到状态 → 已签就跳过
      ↓
POST 领积分 → 写回 KV
```

三条边界：

- **不存密码**：只有 refreshToken 和设备密钥，明文只存在于 Cloudflare 的内存里
- **不上传别处**：只跟 Trae 官方服务通信，没有任何自建服务器中转
- **不改 Trae 本体**：全程只是调用接口，不碰你电脑上的任何文件

## 六、命令行部署（可选）

装过 Node.js 的话可以不用网页版：

```bash
npm install -g wrangler
wrangler login
cd cloudflare

# 建 KV，把输出里的 id 填进 wrangler.toml
wrangler kv namespace create KV

# 三个机密
wrangler secret put ADMIN_TOKEN
wrangler secret put MASTER_KEY
wrangler secret put CRON_SECRET

wrangler deploy
```

`wrangler.toml` 已经写好了，改一下 `id` 就能用。

## 七、常见问题

**Q：登录链接打开报「网络错误」？**
A：链接必须原样打开，别改参数。如果是在微信里打开，改用系统浏览器。

**Q：粘贴回调地址提示「登录上下文已过期」？**
A：登录链接 15 分钟有效，重新点「生成登录链接」再走一遍。

**Q：跳过授权直接提示没有授权码？**
A：复制地址时确认是 `127.0.0.1:17388/authorize?authCodeInfo=...` 那一整段，不要只复制前半截。

**Q：Cron 到点了没执行？**
A：Cloudflare 的 Cron 最多有几分钟延迟，属正常。也可以点「全部签到」手动确认接口通不通。

**Q：想换 MASTER_KEY？**
A：换完所有账号都解不开，必须全部删掉重新扫码。

**Q：免费额度够吗？**
A：一个账号一年约 365 次签到 + 365 次状态查询 ≈ 730 次请求，免费额度是 10 万次/天。

**Q：能托管多少个账号？**
A：技术上不限，受 KV 写入 1000 次/天限制，日常几十个没问题。

## 八、数据与隐私

- 所有账号数据存在**你自己 Cloudflare 账号**的 KV 里，不经过任何第三方
- 每条记录用随机 salt + IV 单独加密，密钥只存在于 Worker 的环境变量
- 控制台接口只返回标签、状态、积分，**从不返回令牌或私钥**（自检脚本里有专门一项验证这点）
- 删账号 = 删 KV 记录，不可恢复（但 Trae 那边的登录状态不受影响）
